# AI 자동매매 시스템 v1.0

## 1. 프로젝트 개요
이 시스템은 파이썬을 이용하여 주식 데이터를 수집, 분석하고 AI 모델을 통해 매매 전략을 수립하여 자동으로 거래하는 것을 목표로 합니다.

## 2. 시스템 구조
- **32비트 "운전석"**: Kiwoom API와 통신하여 실시간 데이터를 처리하고 주문을 실행합니다. (`trader_bot_32bit` 폴더)
- **64비트 "엔진 연구소"**: 대용량 데이터 처리 및 AI 모델 훈련을 담당합니다. (`ai_research_64bit` 폴더)

## 3. 설치 방법
이 프로젝트를 실행하기 위해 필요한 라이브러리 목록입니다.
(여기에 `requirements.txt` 파일 내용을 붙여넣거나, 설치 방법을 설명합니다.)

## 4. 사용 방법

### A. 일일 작전 준비 (매일 장 시작 전)
1. `ai_research_64bit` 폴더로 이동합니다.
2. `py -3.13 run_daily_routine.py`를 실행하여 데이터 최신화 및 모든 AI 모델 훈련을 한번에 수행합니다.

### B. 실시간 자동매매
1. (터미널 1) `trader_bot_32bit` 폴더에서 `py -3.9-32 trader_gui.py`를 실행합니다.
2. (터미널 2) `ai_research_64bit` 폴더에서 `py -3.13 ai_controller.py`를 실행합니다.
3. GUI 창에서 로그인 및 모니터링 시작 버튼을 클릭합니다.
